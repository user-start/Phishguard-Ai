# 🛡️ PhishGuard-AI

### AI-Powered Chrome Extension for Real-Time Phishing Email Detection
---

## 📌 Overview

**PhishGuard-AI** is an intelligent Chrome-based browser extension designed to detect phishing emails in real time using AI-powered analysis and security heuristics.

The extension scans suspicious email content, links, sender information, and malicious patterns to help users identify phishing attacks before interacting with harmful emails.

Built with cybersecurity principles and modern browser extension architecture, PhishGuard-AI aims to provide a lightweight, fast, and user-friendly protection layer for everyday email users.

## 🧠 How It Works

PhishGuard-AI analyzes multiple parameters from an email:

* Email content and language patterns
* Suspicious URLs and redirected links
* Sender authenticity
* Common phishing keywords
* Social engineering indicators
* Domain mismatches
* Urgency or fear-based language

The AI engine processes these indicators and classifies the email as:

| Threat Level  | Meaning                             |
| ------------- | ----------------------------------- |
| 🟢 Safe       | Legitimate email detected           |
| 🟡 Suspicious | Potential phishing indicators found |
| 🔴 Dangerous  | High probability phishing attempt   |

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/phishguard-ai.git
```

### 2️⃣ Open Chrome Extensions

Go to:

```bash
chrome://extensions/
```

### 3️⃣ Enable Developer Mode

Turn ON **Developer Mode** from the top-right corner.

### 4️⃣ Load the Extension

Click:

```bash
Load unpacked
```

Then select the project folder.
